Accédez rapidement à toutes les sections de votre plateforme de location de matériel (interface publique, console d'administration, présentation interactive) et relancez le serveur local en un clic.

⚡ Comment lancer le serveur local

Ouvrez un terminal (ex: Ctrl + Alt + T) et collez l'une des commandes suivantes :

Option 1 (Production rapide, stable) :
cd "/home/yannick/Calvino Location" && npm run start
Option 2 (Mode Développement avec rechargement à chaud) :
cd "/home/yannick/Calvino Location" && npm run dev
Option 3 (Recompiler après modification du code) :
cd "/home/yannick/Calvino Location" && npm run build && npm run start
